# Test Data Notes

SauceDemo is a public demo application. Use only its published demo accounts and non-sensitive dummy customer details.

- Standard user: `standard_user`
- Demo password: `secret_sauce`
- Locked account for manual negative testing: `locked_out_user`
- Example dummy checkout data: first name `Test`, last name `User`, postal code `440001`

Do not use real passwords, personal information, payment cards, or production accounts.
